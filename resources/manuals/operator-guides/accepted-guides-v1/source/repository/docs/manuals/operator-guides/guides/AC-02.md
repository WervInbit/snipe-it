## Purpose

Replace the current or administrator-issued temporary password with a private
password known only to the user.

Version 3 uses a tight rectangular focus around `Wachtwoord wijzigen`, leaves
the three password fields unobscured, and places the red no-sharing warning
directly below the step 3 body. Help handoffs use the referenced guide's
family color, symbol, code, and full name.

## Steps

1. `Open Wachtwoord wijzigen` - open the account menu and choose the password
   change action.
2. `Vul de drie velden in` - enter the current or temporary password, enter the
   new private password, and enter the same new password again. Follow the
   visible password rules and do not reuse the temporary value.
3. `Sla het nieuwe wachtwoord op` - choose `Opslaan` and confirm the success
   message. Use the new password from now on.

## Step-Specific Stops

- Step 2: do not show or send the new password to an administrator or colleague.
- Step 3: if the save fails, read the visible password requirement and correct
  only the indicated field.

## Compact Help

- `Tijdelijk wachtwoord werkt niet` - ask the administrator to use USR-03
  again; do not keep guessing.
- `Regel wordt afgekeurd` - follow the visible complexity message.
- `Geen huidig wachtwoord` - ask a supervisor to follow USR-03.
- `Wachtwoord vergeten` - ask a supervisor to start USR-03.
