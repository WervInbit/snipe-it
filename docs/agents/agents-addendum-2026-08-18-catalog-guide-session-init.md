# Catalog Guide Session - 2026-08-18

## Objective

Investigate and create the first extensive operator guidance for catalog
management, beginning with `CAT-00 Catalogus begrijpen` and `CAT-01 Model en
modelnummer aanmaken`.

## Working Rules

- Preserve every accepted guide artifact and all unrelated working-tree changes.
- Use the shared operator-guide components, registry, evidence catalog, and QA
  checks instead of a one-off layout.
- Verify the deployed model, model-number, attribute, component, and duplication
  behavior before writing operator instructions.
- Use controlled development captures only as internal evidence; printed URLs
  remain `https://snipe.inbit/`.
- Treat the first generated catalogue versions as working drafts until exact
  versions are explicitly accepted.

## Initial Scope

1. Audit current guide standards and prior recurring review failures.
2. Define the catalogue guide family and the chapter/guide boundaries.
3. Produce evidence-backed `CAT-00` and `CAT-01` draft specifications and PDFs.
4. Render and inspect every page before presenting the drafts for review.

## Outcome

- Audited the existing guide system, recurring screenshot/focus/layout errors,
  and deployed catalogue behavior before writing the operator copy.
- Added CAT-00 through CAT-06 specifications and registered the CAT family in
  the shared component/runtime system.
- Captured eight canonical read-only catalogue evidence states. Example create
  forms were filled but not submitted; no model or model number was created.
- Generated and fully inspected CAT-00 v1 (four pages) and CAT-01 v1 (five
  pages). Both remain working drafts awaiting exact-version review.
- Added generator checks for context-column crossing, title/version overlap,
  registered component bounds, and the existing shared badge/reference rules.
- CAT-02 is the next generation target. CAT-06 cannot become an internal review
  candidate until the source-recording policy is decided.
