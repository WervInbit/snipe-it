## Reader And Reasoning

Intended role: Admin. Starting context: Existing exact object, known impact and preserved old values.
Outcome: Only the selected maintenance change is saved or applied and its known affected outcomes are verified.

Required alignment: Current lifecycle controls and a distinct owning route for in-use numeric aggregation.

Chosen reader improvement: An A-H index separates independent tasks; both code and specification/relationship alternatives are explicit before acting.

Preserved support: Existing eight-page maintenance coverage, impact checks, saved verification and no browser definition Delete.

Placement/preservation tradeoff: Nine pages suit eight independent maintenance jobs. Local numbering is legitimate within a selected route; the new rule is not a compulsory ninth execution step.

## Actions And Choices

- Page 1 selects A-H; other route pages are not follow-up tasks.
- A/page 2: Active/Deprecated code. B/page 3: default selection A OR unused-code removal B.
- C/page 4: remove direct attribute OR expected-component row, then save/reopen/inspect affected assets.
- D/page 5: hide/restore the whole attribute. E/page 6: maintain one saved Enum option.
- F/page 7: activate/deactivate a reusable component definition. G/page 8: remove a saved child OR contribution, then Save Changes.
- H/page 9: retain or change an in-use numeric aggregation rule after impact checks, then compare real affected examples.

## Concrete Changes

- Keuze-index A-H; andere pagina's zijn zelfstandige onderhoudstaken.
- Standaardcode OF ongebruikte code verwijderen, en de verschillende rijsoorten verwijderen, zijn expliciete alternatieven.

- De verwijderroute heeft een voorwaardelijke impactcontrole in plaats van een algemene rode STOP-balk; echte Admin-acties blijven leesbaar.

## Evidence, Checks And Limits

The mounted application is the separate refurbisher-followups checkout,
not the root checkout. Source fingerprints, actual actors, Dutch locale,
owned synthetic fixtures and save/trial boundaries are recorded in the batch
provenance. Genuine English strings and narrow native status-choice text
remain product gaps. Header roles preserve the intended task allocation;
local seeded/custom grants can be wider than the operational-role document.
Physical printing/component work, destructive catalogue branches and an
unfamiliar-reader/A4 paper trial are unperformed. Artifact checks and editorial
read-back do not establish reader performance or exact acceptance.

The [batch review](remaining-guides-2026-10-20.md) records shared reconciliation,
actual UI trials, unperformed routes and final preservation/check results.
