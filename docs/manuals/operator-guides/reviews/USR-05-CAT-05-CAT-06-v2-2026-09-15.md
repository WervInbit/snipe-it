## Evidence Provenance And Safety

Eight new canonical images bring evidence to 119 files. Browser interactions
used real local pages and read-only navigation, with no injected result text,
fake warnings or permission-control manipulation. Full-page raw captures can
contain browser stitching seams outside the used regions; the printed crops
were visually checked and exclude those seams.

USR-05 used one owned, memberless local fixture group named Catalogus lezen.
The guarded helper requires APP_ENV local and APP_URL host dev.inbit and refuses
a name collision or any group with members. It created group 5, assigned no
users, and removed that same group after capture. No existing group's rights or
memberships were changed. Five checks against the real resolver passed using
in-memory users/groups: view allowed, create denied, Admin denied, a second
group can grant create, direct user denial wins. This is not a browser-user
trial. A final inspect returned no remaining fixture.

All catalogue captures were read-only. No model number, attribute option,
override, definition, component or asset was changed or deleted. Existing
Docker services were reused and left running. No migrations, PHPUnit database
tests, deployments or commits were performed.

## Open Before Acceptance

1. Superadmin: carry out the printed controlled-user browser trial, including
   at least one permitted and one denied task and known direct/group rights.
2. Admin: execute lifecycle/cleanup routes on an agreed disposable dataset,
   including blocked Primary/in-use deletion, restore/default sequence,
   cancelled versus saved removals, multiple affected asset overrides, Enum
   deactivation/removal, and component-derived results. Source inspection and
   screenshots do not prove those end-to-end outcomes.
3. Catalogue owner: review source applicability, define source-retention and
   fallback approval policy, and resolve exact-variant evidence when needed.
   No new source field or workflow is invented by this documentation.
4. Physical A4/first-time operator review and exact-version acceptance; replace
   proof QR placeholders only once the final digital destinations exist.
5. The current source specifications use the new CAT-05/CAT-06 titles. In
   later new PDF versions, update the incoming references in USR-01/02 and
   CAT-00/01/02/03/04; their retained PDFs remain byte-for-byte unchanged here.
