## Changes And Tradeoffs

Impact: guide/evidence/application alignment, with dependent WF-02 v13.
Preserves one page, four steps, five visual placements, the 3A/3B choice,
complete tab-row context, help, completion, and named guide references.

- Replaces the obsolete profile selector/general start screenshot with actual
  numbered profile rows. Start belongs to the selected row; an unrelated
  available profile is not a way around prerequisites.
- Distinguishes Start, Continue, and Edit, including editing completed runs.
  The screenshot for Edit opens the same Pre-Sale Check run whose neutral
  cards appear in step 4. Changed definitions and blockers remain visible.
- Help routes prerequisite, permission, configuration, and repeat/override
  problems to the appropriate work or supervisor. Exceptional starts are not
  presented as ordinary continuation.
- Uses current shared family/reference colors and full reference names.
  The printed version badge and footer explicitly say Niet geaccepteerd.

Benefit: the guide now matches the observed row-based UI and avoids promising
an unrestricted start. Tradeoff: screenshots contain English controls and
development examples with existing blockers. Dutch prose explains them;
these are genuine states, not a demonstrated successful new-run journey.
The compact help delegates exception administration rather than teaching
override writes in the ordinary operator guide.
Main instruction text uses 2.35 mm instead of the earlier 2.55 mm, and main
step headings use 3.6 mm instead of 3.95 mm. These local size differences
should be compared on a physical A4 print before deciding acceptance.
