## Review Boundary

- Keep the established filename stem for each guide and increment its version.
  Rejected version numbers are not reused. Earlier PDFs stay byte-identical.
- Existing accepted password, operational-role, and location policies are not
  silently replaced. Explain unresolved decisions in review notes.
- Retain screenshot frames and their task purposes. Replace a misleading
  screenshot or adjust a crop only to correct a documented evidence defect;
  record the exact exception instead of claiming pixel equivalence.
- Compare every revised page with the selected baseline for image count,
  help, page count, text changes, containment, and reading order. Inspect the
  rendered PDFs. Technical checks do not replace physical/user validation.
- USR-05, CAT-05, and CAT-06 remain planned dependencies. Provide a role and
  return route where useful; do not represent their specifications as PDFs.
- This pass improves the existing guides; it does not certify that every
  independent-audit finding, policy question, or production evidence gap is closed.
