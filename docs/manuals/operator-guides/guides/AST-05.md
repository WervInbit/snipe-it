## Purpose

Review the transferred asset and its evidence, then record whether it is
released or returned for correction.

The current draft uses actual `QA Hold`, `Ready for Sale`, and `Being Processed`.
Protected release requires reading and confirming the displayed dialog.
Missing work follows Cancel and repair; an authorized override is a separate,
reasoned exception. Every status decision ends with checking the saved result.

## Steps

1. `Controleer apparaat en reviewstatus` - compare tag, serial and model/type;
   verify incoming QA Hold. An identity difference halts changes and returns
   to SC-01 Asset vinden en openen; continue after establishing the match.
2. `Lees het actuele werk en de resultaten` - current required work must be
   complete and successful; open the runs and read evidence/notes. Historical
   success does not replace changed or missing required work.
3. `Controleer het apparaat` - compare label, S/N, model type, physical
   condition, registered components, destination, and included parts.
4. `Leg de beslissing vast` - write Statusnotitie before selecting the status.
   Approved: Ready for Sale -> step 5. Repair: Being Processed, assign the
   repair work -> step 6, subject to any displayed confirmation.
5. `Lees en bevestig de statuswijziging` - check old/new status and findings in
   the real dialog before Confirm status change. Issues normally cancel and
   return for correction. Override requires the separate override right and
   an audit reason. Locked-state exit is outside this incoming-QA task; do
   not confuse its exact-tag requirement with scanner serial lookup.
6. `Controleer het opgeslagen besluit` - reopen the same record, read Status
   on Info and the note in Statusgeschiedenis. Release goes to sale; return
   goes to the executor with its repair instruction. Use a larger screen if
   the history table cannot be read on the phone.

The proof names those routes `Ready for Sale` and `Being Processed`.
V9 leaves complete identity, workflow and status/note checks unmarked. Focus
is retained for label locations, the confirmation action and History tab,
where it helps locate or distinguish a target.
