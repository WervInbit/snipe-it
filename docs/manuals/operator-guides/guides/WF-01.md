## Purpose

Open the workflow area from an asset verified with SC-01, identify the first
workflow still to be performed and its guard message, start once or open its existing
run, then check the asset and expected cards. Do not use an unrelated available
profile to bypass a blocked required step.

## Steps

1. `Open Tests / workflows` - use the test icon after SC-01 verifies the asset.
2. `Bekijk de workflowvolgorde` - begin at the first workflow still to be
   performed. A grey follow-up waits for earlier work. In 2A Standard Diagnostics
   has Start and Cleaning is blocked. Order is not permission to execute every profile.
3. Choose one route: `Start` once in that not-started row, or open that
   row's current existing run with `Continue` / `Edit`. Completed runs remain
   editable. A changed definition requires supervisor guidance; do not use an
   older passing historical run to bypass the current row's blocker.
4. `Controleer de kaarten` - confirm asset and expected titles, recognizing
   neutral versus already answered cards; continue with WF-02.

## Stop

Use help when the profile, prerequisites, level restriction, configuration,
or existing run is unclear. Start new / Override is a separately authorized,
reasoned, confirmed exception, not ordinary continuation. A repeat can also
be prohibited. Refer exceptional starts to a supervisor; an override does not
make later dependent workflows eligible.

## Complete When

The correct existing or newly started workflow is open and its expected result cards are visible.
