## Purpose

Open the workflow area from an asset already verified with SC-01, choose the correct profile, start once or continue the correct existing run from the same decision step, then recognize the active result cards.

## Steps

1. `Open tab Tests` - use the test icon after SC-01 has already verified the open asset.
2. `Kies het workflowprofiel` - select the agreed profile.
3. `Start of ga door` - use `Nieuwe workflow starten` once, or use `Doorgaan met bestaande workflow` inside this step when the correct unfinished run already exists.
4. `Controleer kaarten` - confirm the expected result cards are visible.

## Stop

Use the compact help section when the profile or existing run is unclear. Do not start another run when the correct unfinished run already exists.

## Complete When

The correct existing or newly started workflow is open and its expected result cards are visible.
